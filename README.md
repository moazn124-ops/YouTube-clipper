# YouTube Clipper — نسخة أونلاين

أداة ويب لقص جزء محدد من فيديو YouTube واختيار الجودة، باستخدام yt-dlp وFFmpeg.

## النشر بدون كمبيوتر
1. أنشئ مستودع GitHub جديدًا من الهاتف.
2. ارفع الملفات الموجودة في هذا المجلد إلى المستودع.
3. في Render اختر New → Web Service → اربط مستودع GitHub.
4. اختر Docker، وسيقرأ Dockerfile تلقائيًا.
5. بعد النشر ستحصل على رابط موقع تفتحه من الهاتف.

> استخدم الأداة فقط للمحتوى الذي لديك الحق في تنزيله/معالجته، والتزم بشروط YouTube والقوانين المحلية.
